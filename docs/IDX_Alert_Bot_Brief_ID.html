IDX Alert & Direction Sentiment Bot

Bot Telegram 24/7 berbasis Vercel Serverless Webhook + Cron yang menggabungkan Forecast Arah Harga 5 Hari (Walk-Forward ML), Indikator Teknikal (.JK), Sentimen Berita RSS (30 Hari Terakhir), dan Cross-Check Kas XBRL.

Lokasi Project: Desktop/idx-alert-bot Runtime: Python 3.11+ · aiogram 3.x · FastAPI · scikit-learn Status: Teruji (5/5 pytest passed)

1. Cara Kerja Bot (Pipeline 4 Tahap per Saham)

1 · Data Pasar & Indikator (.JK)

Mengambil data OHLCV 2 tahun dari Yahoo Finance dengan parser angka aman (anti-bug koma ribuan), lalu menghitung:

  • MA20 & MA50 (Uptrend / Downtrend / Sideways)
  • RSI(14), momentum 1D/5D/20D, & volatilitas 20 hari
  • Volume Spike Guard: peringatan rawan kejar jika volume ≥ 3x rata-rata & harga naik ≥ 3%
2 · Walk-Forward Forecast 5 Hari

Model LogisticRegression dilatih secara expanding-window (tanpa bocoran data masa depan) dengan target:

  • Target Naik = return 5 hari ke depan > 0.4% (biaya transaksi)
  • Menghasilkan P(Naik) & P(Turun)
  • Mengukur Akurasi OOS, Win-Rate Naik, & Avg Net Return
3 · Berita RSS Terbaru (when:30d)

Menarik berita Google News 30 hari terakhir (urut terbaru dulu) dan menilai sentimen secara deterministik:

  • POSITIF (+5 poin skor): dividen, laba naik, kontrak baru, buyback
  • PERHATIAN (-8 poin skor): suspensi, UMA, FCA, PKPU, rugi
  • NETRAL (0 poin)
4 · Cross-Check Kas XBRL

Menghubungi API idx-cash-radar.vercel.app untuk memeriksa kesehatan neraca kas emiten:

  • Menampilkan Cash Coverage, Sloan Ratio, & status radar
  • Jika flag TEKANAN_LIKUIDITAS atau DIVERGENSI_AKRUAL aktif, skor komposit otomatis diturunkan (-10 poin) dan diberi label WASPADA.

3. Daftar Perintah Bot Telegram

Perintah Fungsi
/cek <KODE>
atau ketik ADRO		Menjalankan analisis lengkap (Harga, RSI, Tren, Forecast 5H, Backtest OOS, Berita RSS, Kas XBRL) untuk 1 saham.
/morningMemindai watchlist (atau 10 saham default) dan mengurutkan dari skor sentimen tertinggi ke terendah.
/watch <KODE>Menambahkan saham ke watchlist pribadi untuk menerima alert otomatis pukul 08:45 & 18:00 WIB.
/unwatch <KODE>Menghapus saham dari watchlist.
/watchlistMelihat daftar saham yang sedang dipantau.

4. Arsitektur 24/7 di Vercel (Laptop Mati Tetap Jalan)

Bot mendukung dua mode eksekusi: Polling Lokal (python -m src.bot.main) dan Serverless Webhook + Cron (api/index.py) untuk Vercel.

Webhook Real-Time

Setiap chat masuk dikirim Telegram ke POST /api/webhook di Vercel dan langsung dibalas tanpa perlu laptop menyala.

Cron 08:45 & 18:00 WIB

vercel.json & GitHub Actions (cron_alerts.yml) menembak /api/cron/morning & /api/cron/evening setiap hari bursa (Senin–Jumat).

Watchlist Serverless

Di Vercel, isi env DEFAULT_CHAT_ID & DEFAULT_WATCHLIST agar cron tetap mengirim alert meski filesystem serverless tidak persisten.

5. Panduan Deploy Cepat ke Vercel (3 Langkah)

  1. Upload ke GitHub: Push folder Desktop/idx-alert-bot ke repositori GitHub baru, lalu import project tersebut di dashboard Vercel.
  2. Isi Environment Variables di Vercel:
    • TELEGRAM_BOT_TOKEN: token bot dari @BotFather
    • DEFAULT_CHAT_ID: ID Telegram Anda (cek via @userinfobot)
    • DEFAULT_WATCHLIST: daftar kode saham dipisah koma, misal ADRO,BBRI,BBCA,TLKM,ANTM
    • CRON_SECRET: kata sandi acak (opsional, untuk mengamankan endpoint cron)
  3. Aktifkan Webhook (1 kali): Setelah deploy berhasil, buka URL berikut di browser:
    https://<nama-project-vercel>.vercel.app/api/set-webhook
    Jika muncul {"ok": true}, bot sudah aktif 24/7.
Disclaimer: Bot ini adalah alat bantu riset kuantitatif & filter sentimen berbasis data historis. Hasil probabilitas arah dan backtest out-of-sample bukan jaminan pergerakan harga di masa depan dan bukan rekomendasi beli/jual.
